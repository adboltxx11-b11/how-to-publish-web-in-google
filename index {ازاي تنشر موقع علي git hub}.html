🚀 ازاي تنشر موقعك على GitHub

٦ خطوات بسيطة وموقعك يبقى أونلاين برابط https ومجاني. الصور رسومات توضيحية لشكل الشاشة، وممكن شكل GitHub يتغير شوية مع الوقت.

1اعمل حساب على GitHub

ادخل على github.com/signup واكتب إيميلك وباسورد واسم مستخدم (Username). وبعدها أكد الإيميل من الرسالة اللي هتوصلك.

اسم المستخدم هيظهر في رابط موقعك، فاختار اسم بسيط بالإنجليزي.

2اعمل Repository جديد

من أعلى الصفحة دوس على علامة + واختار New repository. اكتب اسم للمشروع (مثلاً my-site) واختار Public وبعدها Create repository.

لازم يكون Public عشان GitHub Pages المجاني يشتغل.

3ارفع ملف index.html

داخل المشروع دوس uploading an existing file واسحب ملف index.html على الصفحة، وبعدها دوس Commit changes تحت.

اسم الملف لازم يكون index.html بالحروف الصغيرة بالظبط، عشان هو اللي بيفتح لما حد يدخل على الرابط.

4افتح Settings ثم Pages

من تبويبات المشروع فوق دوس Settings، وبعدها من القايمة الجانبية اختار Pages.

5اختار الفرع وفعّل النشر

تحت Source اختار Deploy from a branch. وتحت Branch اختار main و / (root)، وبعدين دوس Save.

6استنى دقيقة وافتح الرابط

النشر بياخد من دقيقة لدقيقتين. اعمل ريفريش للصفحة وهيظهرلك الرابط، شكله https://اسمك.github.io/اسم-المشروع/. ابعته لأي حد وهيفتحه.

عشان تعدّل الموقع بعدين، ادخل على الملف في GitHub، دوس أيقونة القلم، عدّل واعمل Commit، والتعديل بينزل تلقائي.
